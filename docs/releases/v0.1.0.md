# BabelCodex v0.1.0

## 发布说明

BabelCodex v0.1.0 是一个面向个人本地使用的 PDF 高保真翻译开发版，使用
BabelDOC 负责 PDF 解析与排版，并通过官方 Codex SDK 提供翻译能力。本版本
提供 Windows x64 GUI 可执行文件及包含必要运行组件的完整 portable 7z 压缩包。

本项目不是托管式翻译服务、多租户 SaaS，也不是 OpenAI 兼容 API 的替代品。

## Release 资产

- `BabelCodex-v0.1.0-windows-x64.exe`：Windows x64 Tauri GUI 可执行文件本体。
- `BabelCodex-v0.1.0-windows-x64-portable.7z`：完整便携压缩包，包含：
  - `BabelCodex.exe`：GUI 可执行文件；
  - `config/config.yaml`：便携运行配置；
  - `resource/bin/babelcodex-service.exe`：PyInstaller 构建的 Python service
    sidecar，负责 JSONL 协议、任务编排和 BabelDOC worker 调用。

压缩包不包含安装器、用户 PDF、任务状态、日志、缓存、凭据或私有术语表。
运行时需要写入的 `cache/`、`logs/` 和 `output/` 目录会在首次运行时按需创建。

CI 会在上传前解压压缩包，并严格校验上述三个必要文件均存在，且归档中没有
额外文件。

## 已实现能力

- BabelDOC 0.6.x 兼容边界，当前观测版本为 0.6.4。
- 使用官方 `openai-codex` SDK 和用户的 Codex/ChatGPT 登录路径；不提取 cookie，
  不调用未公开 ChatGPT HTTP 接口，也不会静默切换到单独计费的 API key。
- 通过 worker process 执行单次 PDF 翻译流程。
- GUI、CLI 和 MCP 共用版本化 JSONL sidecar 协议及 Application Service。
- 保留富文本/公式占位符、URL、引用等受保护内容，并进行输出校验。
- 验证失败时使用受限重试策略，并区分认证、配置、输入、worker、输出等错误类别。
- 持久化任务状态、产物清单校验、失败重试、PDF 输出 QA 和 worker 崩溃恢复。
- YAML-only portable 配置；配置、缓存、日志、输出和只读资源均相对于便携根目录。
- 设置、日志脱敏、受限 PDF staging 和首次输出目录确认。
- Translation Gateway、SQLite 翻译缓存、术语表、文档上下文及 mock batching benchmark。
- 受限本地 stdio MCP 操作；不提供任意 shell 执行或无限制文件删除。
- Tauri 2 + React/TypeScript GUI。

## Windows 验收边界

GitHub Actions 构建成功表示托管 Windows 环境能够完成构建和归档校验，**不等于**
完整的 Windows 原生验收已经完成。以下项目仍需单独执行并记录：

- 全新 Windows 用户配置下的首次输出目录确认；
- 原生文件选择器、Unicode/空格/盘符路径和权限；
- 取消、重连、sidecar 重启、窗口生命周期；
- 125%、150%、200% DPI、键盘导航和 NVDA；
- 清洁用户环境下的安装/升级/卸载行为；
- Defender/SmartScreen、签名、SBOM 和发布安全审计；
- MSI/NSIS 安装器一致性（如适用）；
- 已授权的真实 Codex 登录、真实 PDF 和长文档验收。

权威状态和未执行原因记录在 `docs/validation/windows.md`。在这些平台专项检查
完成前，整体状态仍为 `WINDOWS_VERIFICATION_PENDING`。

## 安装与首次运行

本版本是 unsigned development release，不是签名安装器。使用完整 portable 压缩包
时，请将其解压到具有写权限的目录，并从其中的 `BabelCodex.exe` 启动。单独使用
`.exe` 本体不会包含 sidecar，不能替代完整 portable 压缩包。

实时翻译需要用户完成真实 Codex/ChatGPT 登录；测试和 Release 构建不会发起真实
Codex 请求。请勿将用户 PDF、日志、任务状态、缓存、凭据或私有术语表提交到仓库
或重新打包进公开 Release。

## 已知限制

- GUI 可执行文件未签名，Windows SmartScreen 可能显示警告。
- portable 压缩包是可移动目录包，不是 MSI/NSIS 安装器。
- sidecar、首次启动资源路径和完整 portable 交互仍需在目标 Windows 设备上验收。
- 浏览器模式 WDIO、原生桌面操作、安全产品和真实 Codex/PDF 验证可能受环境限制。
