# Windows 验证历史归档

本目录存放 `docs/validation/windows.md` 中已完成轮次的完整运行记录。

## 归档规则

1. 文件命名 `windows-YYYY-MM.md`，按月份归档；一轮验证结束并写回结论后，其完整记录（命令、环境、输出摘要、错误证据）移入对应月份文件。
2. 归档记录保留原始日期、命令、环境与结论；历史 `FAIL` 不得改写为 `PASS`，已解决的问题只能以追加"后续解决"条目的方式说明。
3. 当前活跃队列（WVQ）、下一轮 handoff 与最新结果摘要只在 `docs/validation/windows.md` 维护；归档文件不得重复或覆盖这些内容。
4. 截图等大文件证据存放在本目录对应月份文件旁，并在月份文件中以相对路径引用。

## 当前内容

尚未归档任何历史轮次。第一轮 Windows 验证的完整记录见 `../windows.md`。
